# blincus v2 Simplification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the bashly-generated, template-heavy blincus with a single hand-written bash script that creates/enters an Incus container per project directory, with the directory mounted inside and X11/Wayland/audio/GPU forwarded to the host.

**Architecture:** One `blincus` script (~300 lines, plain bash) with three commands (`enter`, `ls`, `rm`). Host-side devices live in one idempotently-created Incus profile named `blincus`; container-side user setup is inline cloud-init generated at launch time. Containers are bound to project paths via the `user.blincus.project` instance config key.

**Tech Stack:** bash ≥ 4, Incus ≥ 6.x (host has 7.2), jq, cloud-init images (`images:*/cloud`), shellcheck/shfmt via podman.

**Spec:** `docs/superpowers/specs/2026-07-07-blincus-simplification-design.md`

## Global Constraints

- Default image: `images:debian/trixie/cloud`, stored as `image=` in `~/.config/blincus/config`.
- Incus profile name: `blincus`. Instance config key: `user.blincus.project` (absolute project path).
- Container user: host `$USER`, uid `1000`, shell `/bin/bash`, sudo NOPASSWD.
- Socket staging dir inside container: `/mnt/.blincus/` (`X0`, `wayland-0`, `pulse-native`).
- X11 auth: `xhost +si:localuser:$USER` — never `xhost +`.
- All scripts: `set -euo pipefail` (bash) and must pass shellcheck.
- Work happens on branch `feat/simplify-blincus` (already created, spec committed).
- Do not touch `vscode.sh` (user's untracked scratch file) or `empty-incus.sh` (kept as-is).

- [ ] **Step 1: Write the script**

Replace the entire contents of `blincus` with:

```bash
#!/usr/bin/env bash
#
# blincus - disposable Incus dev containers for the current directory
#
# enter:  create-or-enter the container for $PWD, with the directory
#         mounted inside and X11/Wayland/audio/GPU forwarded to the host.
# ls:     list blincus-managed containers.
# rm:     delete a container (default: the one for $PWD).

set -euo pipefail

VERSION="2.0.0"
CONFIG_FILE="${BLINCUS_CONFIG:-$HOME/.config/blincus/config}"
DEFAULT_IMAGE="images:debian/trixie/cloud"
PROFILE="blincus"

die() {
	echo "error: $*" >&2
	exit 1
}

usage() {
	cat <<EOF
blincus $VERSION - disposable Incus dev containers for the current directory

Usage:
  blincus enter [-i IMAGE]   create or enter the container for the current directory
  blincus ls                 list blincus containers
  blincus rm [NAME]          delete a container (default: the one for the current directory)
  blincus --help | --version

The current directory is mounted at ~/<dirname> inside the container.
X11, Wayland, audio, and GPU are forwarded so GUI apps appear on the host.

Config: $CONFIG_FILE (image=$DEFAULT_IMAGE)
EOF
}

require_deps() {
	command -v incus >/dev/null || die "incus not found - https://linuxcontainers.org/incus/docs/main/installing/"
	command -v jq >/dev/null || die "jq not found - install it with your package manager"
}

load_config() {
	if [[ ! -f "$CONFIG_FILE" ]]; then
		mkdir -p "$(dirname "$CONFIG_FILE")"
		echo "image=$DEFAULT_IMAGE" >"$CONFIG_FILE"
		echo "Created config at $CONFIG_FILE"
	fi
	IMAGE=$(awk -F= '$1 == "image" {print $2}' "$CONFIG_FILE")
	IMAGE=${IMAGE:-$DEFAULT_IMAGE}
}

# Sanitize a directory path into a valid incus instance name.
project_name() {
	local slug
	slug=$(basename "$1" | tr '[:upper:]' '[:lower:]' | sed 's/[^a-z0-9-]/-/g; s/^[-0-9]*//; s/-*$//')
	echo "${slug:-project}"
}

# Print the name of the container bound to a project path, if any.
find_by_project() {
	incus ls --format json | jq -r --arg p "$1" \
		'.[] | select(.config."user.blincus.project" == $p) | .name' | head -1
}

container_exists() {
	incus info "$1" >/dev/null 2>&1
}

container_status() {
	incus ls --format json | jq -r --arg n "$1" '.[] | select(.name == $n) | .status'
}

# Create the shared host-side profile from the live environment (idempotent).
ensure_profile() {
	incus profile show "$PROFILE" >/dev/null 2>&1 && return 0
	echo "Creating Incus profile '$PROFILE'..."
	incus profile create "$PROFILE" >/dev/null
	incus profile set "$PROFILE" security.nesting true
	incus profile set "$PROFILE" raw.idmap "both $(id -u) 1000"
	incus profile device add "$PROFILE" gpu gpu gid=44 >/dev/null
	if [[ -S /tmp/.X11-unix/X0 ]]; then
		incus profile device add "$PROFILE" x11 disk \
			source=/tmp/.X11-unix/X0 path=/mnt/.blincus/X0 >/dev/null
	fi
	if [[ -n ${WAYLAND_DISPLAY:-} && -S "${XDG_RUNTIME_DIR:-}/${WAYLAND_DISPLAY}" ]]; then
		incus profile device add "$PROFILE" wayland disk \
			source="$XDG_RUNTIME_DIR/$WAYLAND_DISPLAY" path=/mnt/.blincus/wayland-0 >/dev/null
	fi
	if [[ -S "${XDG_RUNTIME_DIR:-}/pulse/native" ]]; then
		incus profile device add "$PROFILE" audio disk \
			source="$XDG_RUNTIME_DIR/pulse/native" path=/mnt/.blincus/pulse-native >/dev/null
	fi
}

# Emit cloud-init user-data for this host user. No files on disk, no templating.
generate_user_data() {
	local sshkey="" key fullname
	for key in "$HOME"/.ssh/id*.pub; do
		[[ -f $key ]] && sshkey=$(<"$key") && break
	done
	fullname=$(getent passwd "$USER" | cut -d: -f5 | cut -d, -f1)

	cat <<EOF
#cloud-config
users:
  - name: $USER
    uid: "1000"
    gecos: $fullname
    shell: /bin/bash
    groups: [adm, video, sudo]
    sudo: ALL=(ALL) NOPASSWD:ALL
    lock_passwd: true
EOF
	if [[ -n $sshkey ]]; then
		cat <<EOF
    ssh_authorized_keys:
      - $sshkey
EOF
	fi
	cat <<'EOF'
write_files:
  - path: /usr/local/bin/blincus-sockets
    permissions: "0755"
    content: |
      #!/bin/sh
      # Link host sockets (mounted under /mnt/.blincus) into the places
      # clients expect. /tmp and /run/user are fresh tmpfs at boot, so the
      # host mounts can't target them directly.
      run_dir=/run/user/$(id -u)
      if [ -e /mnt/.blincus/wayland-0 ]; then
        ln -sf /mnt/.blincus/wayland-0 "$run_dir/wayland-0"
      fi
      if [ -e /mnt/.blincus/pulse-native ]; then
        mkdir -p "$run_dir/pulse"
        ln -sf /mnt/.blincus/pulse-native "$run_dir/pulse/native"
      fi
      if [ -e /mnt/.blincus/X0 ]; then
        mkdir -p /tmp/.X11-unix
        ln -sf /mnt/.blincus/X0 /tmp/.X11-unix/X0
      fi
  - path: /etc/systemd/user/blincus-sockets.service
    content: |
      [Unit]
      Description=Link blincus host sockets into place
      After=local-fs.target
      [Service]
      Type=oneshot
      ExecStart=/usr/local/bin/blincus-sockets
      [Install]
      WantedBy=default.target
  - path: /etc/profile.d/blincus.sh
    content: |
      export DISPLAY=:0
      if [ -e /mnt/.blincus/wayland-0 ]; then
        export WAYLAND_DISPLAY=wayland-0
      fi
runcmd:
  - systemctl --global enable blincus-sockets.service
EOF
}

grant_x11() {
	if [[ -n ${DISPLAY:-} ]] && command -v xhost >/dev/null; then
		xhost "+si:localuser:$USER" >/dev/null
	fi
}

create_container() {
	local name=$1 project=$2 image=$3 mountdir
	ensure_profile
	echo "Creating container '$name' from $image..."
	incus launch "$image" "$name" -p default -p "$PROFILE" \
		--config user.user-data="$(generate_user_data)" \
		--config user.blincus.project="$project"
	echo "Waiting for cloud-init..."
	if ! incus exec "$name" -- cloud-init status --wait >/dev/null; then
		echo "error: cloud-init failed in '$name'." >&2
		echo "  inspect: incus exec $name -- cloud-init status --long" >&2
		echo "  retry:   blincus rm $name && blincus enter" >&2
		exit 1
	fi
	mountdir=$(basename "$project")
	incus config device add "$name" project disk \
		source="$project" path="/home/$USER/$mountdir" >/dev/null
	echo "Mounted $project -> ~/$mountdir"
}

cmd_enter() {
	local image_override=""
	while [[ $# -gt 0 ]]; do
		case $1 in
		-i | --image)
			[[ $# -ge 2 ]] || die "$1 requires an argument"
			image_override=$2
			shift 2
			;;
		*) die "unknown option for enter: $1" ;;
		esac
	done

	local project name mountdir
	project=$(pwd -P)
	name=$(find_by_project "$project")

	if [[ -z $name ]]; then
		name=$(project_name "$project")
		if container_exists "$name"; then
			if [[ -z $(incus config get "$name" user.blincus.project) ]]; then
				die "container '$name' already exists and is not managed by blincus"
			fi
			# same basename, different directory: disambiguate with a path hash
			name="$name-$(echo -n "$project" | sha256sum | cut -c1-4)"
		fi
		create_container "$name" "$project" "${image_override:-$IMAGE}"
	fi

	if [[ $(container_status "$name") != "Running" ]]; then
		echo "Starting '$name'..."
		incus start "$name"
	fi

	grant_x11
	mountdir=$(basename "$project")
	exec incus exec "$name" -- su -l "$USER" -c \
		"cd \"\$HOME/$mountdir\" 2>/dev/null || cd; exec bash"
}

cmd_ls() {
	incus ls --format json | jq -r '
		["NAME", "STATUS", "PROJECT"],
		(.[] | select(.config."user.blincus.project") |
			[.name, .status, .config."user.blincus.project"])
		| @tsv' | column -t -s "$(printf '\t')"
}

cmd_rm() {
	local name=${1:-}
	if [[ -z $name ]]; then
		name=$(find_by_project "$(pwd -P)")
		[[ -n $name ]] || die "no blincus container for $(pwd -P) - see 'blincus ls'"
	else
		container_exists "$name" || die "no container named '$name'"
		[[ -n $(incus config get "$name" user.blincus.project) ]] ||
			die "'$name' is not managed by blincus"
	fi
	local answer
	read -r -p "Delete container '$name'? [y/N] " answer
	[[ $answer == [yY] ]] || {
		echo "aborted"
		exit 0
	}
	incus delete -f "$name"
	echo "Deleted '$name'"
}

main() {
	require_deps
	case ${1:-} in
	enter)
		shift
		load_config
		cmd_enter "$@"
		;;
	ls)
		shift
		cmd_ls
		;;
	rm)
		shift
		cmd_rm "$@"
		;;
	-h | --help | help | "")
		usage
		;;
	-v | --version | version)
		echo "blincus $VERSION"
		;;
	*)
		die "unknown command: $1 (see 'blincus --help')"
		;;
	esac
}

main "$@"
```

# blincus

Disposable [Incus](https://linuxcontainers.org/incus/) dev containers for the
current directory — so project cruft lands in a container, not on your host.

```console
$ cd ~/projects/myapp
$ blincus enter
Creating container 'myapp' from images:debian/trixie/cloud...
Mounted /home/you/projects/myapp -> ~/myapp
you@myapp:~/myapp$ code .        # opens on your host display
```

## What it does

`blincus enter`, run from a project directory:

- creates (or reuses) a container bound to that directory
- mounts the directory at `~/<dirname>` inside the container
- forwards X11, Wayland, and PulseAudio/PipeWire sockets and the GPU,
  so GUI apps — IDEs included — render on the host display
- drops you into a login shell in the project directory

Containers are tracked by project path, so `blincus enter`, `blincus rm`,
and `blincus ls` all just work from inside the project.

## Commands

| Command | What it does |
|---|---|
| `blincus enter [-i IMAGE]` | Create or enter the container for `$PWD` |
| `blincus ls` | List blincus containers and their project dirs |
| `blincus rm [NAME]` | Delete a container (default: the one for `$PWD`) |

## Requirements

- Linux host with [Incus](https://linuxcontainers.org/incus/docs/main/installing/)
  initialized (`incus admin init`)
- `jq`
- `xhost` (for X11 apps; part of `x11-xserver-utils` on Debian)

## Install

```console
$ ./install     # copies blincus to ~/.local/bin + bash completions
```

## Configuration

`~/.config/blincus/config`, created on first run:

```ini
image=images:debian/trixie/cloud
```

Any cloud-init-enabled image works (`incus image list images: cloud`).
Override per-container with `blincus enter -i images:fedora/42/cloud`.

## How the forwarding works

Host sockets can't be mounted directly onto `/tmp` or `/run/user` in the
container (both are fresh tmpfs at boot), so blincus mounts them under
`/mnt/.blincus/` via a shared `blincus` Incus profile and a small systemd
user service links them into place at login. `raw.idmap` maps your host
uid to the container user, and X11 access is granted with
`xhost +si:localuser:$USER` — your user only, not `xhost +`.

Delete the `blincus` profile (`incus profile delete blincus`) after changing
display setups; it's recreated from the live environment on the next launch.
